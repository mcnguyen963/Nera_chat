    Prompts

    This story

    Available before the first message. Adds character state and story event tracking. Balanced is the default: lookup then narration in two requests. Choose Reviewed for an independent model check or Saver for one request per turn.

    After enabling it, choose “Author note” beside the composer to establish characters, relationships, and corrections. Use “In story” for your character's actions.

    Your original story stays intact. Paste a note you reviewed against its transcript. Review sends only the reviewed note to your configured model to build character state for a new copy; the transcript remains read-only history.

    Download an example JSON template. Paste your own final migration JSON, upload a JSON file, or correct a model response below. Local validation makes no LLM request. Evidence must match the reviewed author note. Nothing is published until you create the copy.
