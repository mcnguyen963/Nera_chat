# B20 — previous-summary fallback

Changed js/messages.js and tests/message-chunks.mjs. Deleting the active checkpoint discovers and transactionally rereads candidate summary chunks under a captured history revision. It selects the newest valid earlier summary whose known coverage ends before the deleted order. Folded-message deletion cannot select a summary that includes that deleted source. Unknown coverage falls back to null/0.

Four cases cover previous-summary selection, folded source exclusion, malformed legacy coverage and failed atomic deletion. Final suite 463/463. User deletion adds a session preflight/discovery reads plus candidate chunk transaction reads; normal-turn writes/reads and model calls are unchanged. Conflicts or transaction failure write nothing and ask the user to retry.
